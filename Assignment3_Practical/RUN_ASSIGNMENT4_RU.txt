ПОЛНЫЙ ЗАПУСК ASSIGNMENT 4

1. Скачайте репозиторий GitHub целиком или выполните git clone по инструкции
   в README.md. Для первого запуска нужны Python 3.12 и интернет.
2. Откройте папку Assignment3_Practical. Это историческое имя папки;
   в ней находится и новый проект Assignment 4.
3. Дважды нажмите START_ASSIGNMENT4.cmd.
4. Дождитесь SUCCESS. Полная проверка может занять несколько минут.

Программа по очереди выполняет:
— проверку пяти проектов с тремя seed и 1 080 внутренними подборами;
— повтор Synapse-теста с ранее зафиксированной моделью;
— расчёт сводных таблиц и анализа устойчивости;
— проверку данных, меток и сохранённых результатов исследования.

Новые результаты находятся в outputs_assignment4_ДАТА_ВРЕМЯ:
benchmark/macro_summary.csv — средние результаты моделей;
benchmark/per_project_metrics.csv — результаты по каждому проекту;
benchmark/importance_summary.csv — важность метрик;
holdout/holdout_metrics.csv — результаты Synapse;
benchmark/checks.txt и holdout/checks.txt — выполненные проверки;
run_manifest.json — описание этого повторного запуска.

START_DEMO.cmd — только быстрый показ Synapse.
START_BENCHMARK.cmd — только полная проверка пяти проектов.
START_PILOT.cmd — старый пилот Assignment 3.

Повторный запуск воспроизводит опубликованное исследование.
Он не превращает уже изученный Synapse в новый независимый тест.
