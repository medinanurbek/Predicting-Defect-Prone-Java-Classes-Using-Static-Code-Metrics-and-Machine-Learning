# Подготовка к финальному экзамену RMT

Основная статья: `output/Final_Paper_Kabysheva_Nurbek_Maksatova_Nauryzbay.docx`.
Материал для самостоятельной подготовки: `output/Final_Defence_Guide_EN_RU.docx`.

Статья оформлена на английском в предоставленном двухколоночном шаблоне. Проверенная версия занимает 5 страниц, содержит 20 последовательно цитируемых IEEE-источников, четыре аналитические таблицы и две фигуры. Показатели моделей происходят из выполненного Assignment 4; исходные записи исследования сохранены.

## Что добавлено к Assignment 4

- Введение с явными gap, research question, empirical contribution и проверяемой гипотезой.
- Уточнение временного охвата: по одному историческому релизу каждого проекта; известны даты получения файлов, точные окна регистрации дефектов не установлены.
- Выполненная исследовательская проверка гипотез по пяти средним проектным AP: двухсторонний точный Wilcoxon и Holm для шести сравнений. Необработанные p равны 0.0625, скорректированные — 0.375; значимого превосходства не установлено.
- Результаты тестов обозначены как post hoc и exploratory, поскольку добавлены после просмотра данных. Новые участники, новые обучающие прогоны и новые успешные результаты не выдумывались.
- Два графика из сохранённых результатов; данные и исходники лежат в `figures/` и `analysis/`.
- Проверка библиографии: `references/verified_references.json`; подтверждение минимальных 30% по страницам издателей — `references/indexing_evidence.json`. Для шести публикаций консервативно использована информация об индексировании их журналов. Это не экспорт индивидуальных записей из Scopus/WoS.

## Что нужно сделать команде

1. Заполнить четыре email в начале статьи. Эти поля намеренно оставлены пустыми по просьбе команды.
2. Самостоятельно подготовить презентацию в преподавательском шаблоне. Согласованно она не создавалась в этом комплекте. В пособии есть план слайдов и почти равные части английской речи для четырёх человек.
3. Отрепетировать 10–12 минут с таймером. План — 11 минут, около 2 минут 45 секунд на человека; фактическая длительность зависит от темпа и пауз.
4. Пройти предусмотренную преподавателем проверку в Moodle. Проверка StrikePlagiarism не выполнялась; процент совпадений не заявляется.
5. При возможности распечатать одну копию статьи. В критериях предусмотрен бонус. Русское пособие является материалом для подготовки, а не основной статьёй или содержанием английских слайдов.
6. Каждый участник должен объяснять всю работу и описывать только свой фактический вклад. Назначенная роль не удостоверяет личное выполнение всех скриптов.

Бонус за смешанный количественный и качественный дизайн не заявляется: работа количественная. Обычное обсуждение литературы не превращает её в смешанное исследование. Исторический десятинедельный Gantt не создавался без фактических записей о таком графике.

## Повторение анализа

Из корня репозитория, после подготовки Python 3.12:

```powershell
py -3.12 -m venv Assignment3_Practical\.venv
.\Assignment3_Practical\.venv\Scripts\python.exe -m pip install -r Final_Paper\requirements_analysis.txt
.\Assignment3_Practical\.venv\Scripts\python.exe Final_Paper\analysis\final_statistical_analysis.py
.\Assignment3_Practical\.venv\Scripts\python.exe Final_Paper\analysis\make_figures.py
.\Assignment3_Practical\.venv\Scripts\python.exe Final_Paper\verify_final_submission.py
```

Для полной модели используется `Assignment3_Practical/START_ASSIGNMENT4.cmd`; быстрый повтор Synapse — `START_DEMO.cmd` в той же папке. Перезапуск опубликованного Synapse воспроизводит известный результат и не создаёт новое независимое подтверждение.

## Основные числа

Пять проектов, три seed, 1080 внутренних обучений. LR6: средний AP 0.455, ROC-AUC 0.718, F1 0.383 при пороге 0.5. На Synapse после исключений 243 класса и 86 положительных. При пороге 0.4: TP 61, FN 25, FP 66, TN 91; precision 0.480, recall 0.709, F1 0.573. При 0.5: TP 38, FP 25, F1 0.510. Базовое решение «все положительные» имеет F1 0.523. Эти результаты не означают готовность к внедрению.
